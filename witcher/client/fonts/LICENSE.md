# Шрифты

Все шрифты — под SIL Open Font License 1.1 (https://openfontlicense.org), взяты из пакетов
@fontsource (npm), подмножества cyrillic/latin в woff2:

| Файл | Шрифт | Где используется |
|---|---|---|
| `fira-sans-condensed-*-800-*` | Fira Sans Condensed ExtraBold (© Mozilla, Carrois) | `WName` — названия на картах |
| `fira-sans-condensed-*-400/700-*` | Fira Sans Condensed Regular/Bold | `WEv` — текст карт исследования и событий |
| `neucha-*` | Neucha (© Jovanny Lemonad) | `WText` — текст атак монстров |
| `oswald-latin-600-*` | Oswald SemiBold (© Vernon Adams) | `WNum` — цифры стоимости и уровней |
