# Арт карт

Файлы `*.webp` здесь сгенерированы из фото карт в `Witcher/` скриптом `witcher/tools/art.mjs`:

    SHARP=<путь к модулю sharp> node witcher/tools/art.mjs [actions|monsters|potions|gear]

- карты действий — вся ячейка скана (рамка, медальоны и плашки рисуются поверх, совпадают 1:1);
- монстры — верх упрощённой карты, эликсиры — середина карты;
- снаряжение и спутники (`CONT79-*`, `CONT80-37/39`) — печатная карта целиком.

Свой арт: положите файл с именем, равным ID карты (`W-A-01.jpg`, `MON-05.png`, `POTION-02.webp`,
`CONT79-15.jpg` …), и удалите сгенерированный `.webp` с тем же ID (на ID берётся один файл).
Форматы: jpg, png, webp, svg. Перезагрузите страницу после добавления файлов.
