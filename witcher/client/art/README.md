# Арт карт

Положите сюда изображение с именем, равным ID карты, — и оно заменит сгенерированную заглушку:

- `W-A-01.jpg`, `W-START-03.png` … — карты действий (ID: `witcher/shared/data/gen-data.mjs`);
- `MON-05.jpg` — монстр; `POTION-02.webp` — эликсир; `SKILL-COMBAT.jpg` — трофей навыка.

Форматы: jpg, png, webp, svg. Окно арта на карте — примерно 5:4 (ширина к высоте), обрезается по центру.
Перезагрузите страницу после добавления файлов.
