# Обычная боевая колода монстров

[Все материалы](../README.md) · [Четыре особые карты](<Доп боевая колода.md>) · [Ход монстра в битве](<../Книги правил/База.md#page-25>)

**Источник:** [Боевая колода.jpg](<Боевая колода.jpg>), 2895 × 3596 пикселей, **5 столбцов × 4 строки**, ячейка 579 × 899. Все **20 ячеек заняты лицевыми сторонами**, как в [составе базы](<../Книги правил/База.md#page-5>). `rNcM` — строка и столбец от левого верхнего угла. Номера `MON-ATK-NN` редакционные; повторяющиеся пары эффектов оставлены отдельными экземплярами. Оборот в этом JPG не представлен.

Вверху под рогатым черепом — **удар**, внизу под пастью — **укус**. Это альтернативы: выполняется один объявленный тип атаки, а не обе надписи. Римские **I / II / III в шестиугольниках** рядом с численными шкалами означают **уровень монстра**, в отличие от следов когтей I–IV на особых боевых картах.

## Повторяющиеся тексты и графические шкалы

Сокращения из таблицы ниже полностью раскрываются так:

| Сокращение | Напечатанный текст / графическое значение |
|---|---|
| **Урон N** | «Игрок получает N урона». Рядом нарисовано N следов урона |
| **Алхимия −1; урон 0/1/2** | «Игрок понижает свой навык алхимии на 1, а также получает 0–2 урона согласно уровню монстра»; значки: I — 0, II — 1, III — 2 урона |
| **Сражение −1; урон 0/1/2** | «Игрок понижает свой навык сражения на 1, а также получает 0–2 урона согласно уровню монстра»; значки: I — 0, II — 1, III — 2 урона |
| **Защита −1; урон 0/1/2** | «Игрок понижает свой навык защиты на 1, а также получает 0–2 урона согласно уровню монстра»; значки: I — 0, II — 1, III — 2 урона |
| **Урон 3/4/5** | «Игрок получает 3, 4 или 5 единиц урона в зависимости от уровня монстра»; значки: I — 3, II — 4, III — 5 урона |
| **Урон = защита** | «Игрок получает урон, равный его уровню защиты»; знак урона `=` значок навыка защиты |
| **Урон = алхимия** | «Игрок получает урон, равный его уровню алхимии»; знак урона `=` значок навыка алхимии |
| **Урон = специализация** | «Игрок получает урон, равный его уровню специализации»; знак урона `=` ромб с вопросительным знаком |
| **Урон = сражение** | «Игрок получает урон, равный его уровню сражения»; знак урона `=` значок навыка сражения |
| **Удалить 1** | «Игрок убирает из игры 1 карту из своей руки (если в руке нет карт то верхнюю карту из своей колоды)»; значок горящей карты |
| **Случайный сброс 1/2/3** | «Игрок сбрасывает несколько случайных карт из своей руки в зависимости от уровня монстра»; значки: I — ×1, II — ×2, III — ×3 |

Значки сражения/защиты/алхимии/специализации ссылаются на **навыки**, а не на текущий щит, число эликсиров или обычный добор по планшету. Если навык имеет уровень V, не следует заменять его числом 4 только потому, что соответствующий эффект планшета достигает предела 4.

## Уточнения из правил, не дополнительный текст карт

- Если при случайном сбросе недостаточно карт в руке, недостающие сбрасываются с верха своей колоды.
- Понижение навыка не опускает его ниже 1; достигший 5-го уровня навык не понижается. Это не отменяет сопровождающий урон.
- «Убрать из игры» и «сбросить» — разные операции. Удалённая карта не попадает в сброс.
- Источник всех трёх пояснений: [база, стр. 25](<../Книги правил/База.md#page-25>).
- Эта колода **не** заменяет [20 боевых карт легендарного монстра](<../Легендарные монстры/Атаки.md>).
