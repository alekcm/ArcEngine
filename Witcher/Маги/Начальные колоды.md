# Начальные колоды чародеев

[Все материалы](../README.md) · [Планшеты](Планшеты.md) · [Уникальные действия](<Уникальные карты.md>) · [Порядок эффектов](<../Книги правил/Чародеи.md#page-6>) · [Новые значки](<../Книги правил/Чародеи.md#page-7>)

**Источник:** [Стартовые колоды.jpg](<Стартовые колоды.jpg>), 5790 × 4495 пикселей, **10 столбцов × 5 строк**, ячейка 579 × 899. Все **50 ячеек — лицевые стороны**, по 10 карт каждому из пяти персонажей, как в [составе дополнения](<../Книги правил/Чародеи.md#page-2>). Пустых ячеек и рубашек нет. `rNcM` — строка и столбец от левого верхнего угла; `M-START-NN` — редакционные ID.

На всех 50 картах **стоимость 0**, а справа вверху — эмблема владельца. Принадлежность установлена по совпадению эмблем с планшетами, **не по цвету магической стихии**: r1 — синее солнце Альзура, r2 — зелёный скарабей Филиппы, r3 — розовый полумесяц Ардеи, r4 — фиолетовая круговая схема Отара, r5 — тёмная ладонь с глазом Гехиры. Художественного/особого текста, кроме названий, на картах нет.

## Обозначения

| Краткая запись | Полная расшифровка |
|---|---|
| УN | `[УРОН:N]` |
| БN | `[БАРЬЕР:+N]`, не обычный щит и не энергия |
| ЭN | `[ЭНЕРГИЯ:+N]`; два отдельных значка энергии означают Э2 |
| Д+N | Модификатор добора в конце хода битвы, не немедленное взятие |
| Верх сброса | Взять 1 верхнюю карту своего сброса |
| Любая из сброса | Выбрать и взять 1 любую карту своего сброса, не меняя порядок остальных |
| Вернуть эту | Вернуть именно отмеченную карту в руку |
| Любой цвет | Считать, что эта карта имеет связь любого цвета на ваш выбор |
| Нет | Значок/доплата/напечатанная связь отсутствует |
| Без бонуса | Цветная связь есть, но значка эффекта на ней нет |
| Джокер | Напечатанный общий знак трёх типов местности |

**Доплата** в отдельном столбце означает **необязательный** дополнительный эффект: например, `Э−2 → У3` — можно понизить энергию на 2, чтобы нанести дополнительно 3 урона. Энергетическая цена не является стоимостью приобретения карты. Основные эффекты применяются и без этой доплаты; эффекты ниже неё не добавлены к базовым автоматически. Напечатанные связи перечислены отдельно, их бонус действует лишь при использовании.

## Сверка различий

- В каждой колоде ровно **2 синих, 2 красных, 2 фиолетовых, 2 жёлтых и 2 зелёных** действия; ровно одна карта с джокером местности. Распределение **обычных** местностей не выровнено по предположению: например, у Филиппы три водные карты подряд `r2c8`–`r2c10`.
- Барьер с магическими дугами на этих картах не заменён обычным щитом. Число отдельных значков энергии сохранено, даже если рядом с ними нет арабской цифры.
- **M-START-03** не имеет базового урона: У3 находятся только под доплатой. **M-START-23** не имеет базовых значков: её У1 находится только на зелёной связи. Отсутствие значка не заполнено эффектом другой карты с тем же названием.
- **M-START-11** возвращает верх сброса только через жёлтую связь; **M-START-41/49** за доплату позволяют выбрать **любую** карту сброса. Эти эффекты не объединены.
- Эффект «любой цвет» на M-START-13/15/17 — возможность продолжить эту карту связью выбранного цвета, а не смена собственного красного/фиолетового/жёлтого типа карты.
- Для одного действия порядок по [правилам чародеев](<../Книги правил/Чародеи.md#page-6>): базовый эффект → необязательная оплата и дополнительный эффект → использованная связь; затем следующая карта. Модификаторы добора учитываются на этапе 4, а не превращаются в немедленное взятие.
- [Уникальные действия](<Уникальные карты.md>) в эти наборы из 10 карт не включены и добавляются отдельно по правилам мини-дополнения.
