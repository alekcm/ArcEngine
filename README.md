# ArcEngine

Стартовый набор для 3D-игр в браузере, сделанный **исключительно под LLM-кодинг**.

## Как пользоваться

1. Скачайте репозиторий и откройте папку в кодинг-агенте (Claude Code или другом).
2. Попросите: «Сделай игру, где…».
3. Запустите `run.bat` — игра откроется в браузере. `editor.bat` — редактор сцены и интерфейса.

Нужен только [Node.js](https://nodejs.org).

## Что даёт

- Обвязка из skills позволяющая LLM эффективно работать с набором.
- Готовый мир на Babylon.js: земля с холмами, небо, свет, тени, toon-шейдер, камера.
- Модели FBX и GLB со скелетом и анимациями, звук, игровой интерфейс.
- Веб-редактор: расстановка объектов, настройки, звук, раскладка UI.

## Кампании

При запуске выберите одну из двух самостоятельных игр:

- **Герои Меча и Магии V** — пошаговая стратегия: карта Асхана, замок, армия и тактические бои.
- **Warcraft III: Война за Азерот** — оригинальная low-poly RTS-миссия: Альянс против Орды, добыча золота и леса, строительство, обучение войск, герой-Паладин, орочьи атаки и уничтожение Большого зала.

В Warcraft III: ЛКМ выбирает отряд, протяжка ЛКМ выделяет рамкой, короткий ПКМ отдаёт приказ, перетаскивание ПКМ вращает камеру, СКМ панорамирует карту, WASD/стрелки двигают камеру, колесо меняет масштаб. Крестьянами щёлкните ПКМ по шахте или лесу; для строительства используйте кнопки внизу или B / N / T / Y; обучение — 1 / 2 / 3; способности Паладина — G / V; Space — пауза, R — фокус на штабе, F10 — выбор игры.

## Почему под LLM

- **Ноль зависимостей и сборки** — чистый JS, агенту нечего ломать в npm и бандлерах.
- **Агент знает правила** — `CLAUDE.md` и скиллы в `claude/skills/` описывают архитектуру до первой правки.
- **Агент проверяет себя** — типы и тесты одной командой, линтер сцены и инструменты отладки.
- **Вы — в редакторе, агент — в коде** — числа, объекты и UI лежат в файлах данных: их правите вы, логику пишет агент.
