# ArcEngine

Стартовый набор для 3D-игр в браузере, сделанный **исключительно под LLM-кодинг**.

## Как пользоваться

1. Скачайте репозиторий и откройте папку в кодинг-агенте (Claude Code или другом).
2. Попросите: «Сделай игру, где…».
3. Запустите `run.bat` — игра откроется в браузере. `editor.bat` — редактор сцены и интерфейса.

Нужен только [Node.js](https://nodejs.org).

## Что даёт

- Обвязка из skills позволяющая LLM эффективно работать с набором.
- Готовый мир на Babylon.js: земля с холмами, небо, свет, тени, toon-шейдер, камера.
- Модели FBX и GLB со скелетом и анимациями, звук, игровой интерфейс.
- Веб-редактор: расстановка объектов, настройки, звук, раскладка UI.

## Forbidden Stars — настольная игра по локальной сети

В наборе живёт компьютерная версия **Forbidden Stars** (FFG, 2015): 2–4 игрока, доска из
тайлов систем, приказы, бой, карты событий и варп-штормы. Игра идёт по локальной сети:
один компьютер — сервер, остальные подключаются к нему по ссылке.

### Запуск

```
node tools/fs-server.mjs
```

Сервер поднимается на `0.0.0.0:8080` и печатает адреса:

```
http://localhost:8080/          — этот компьютер
http://192.168.1.5:8080/        — для друзей в этой сети
```

Откройте ссылку (в сетевом варианте — с `?room=КОД`, код покажет хост), выберите фракцию
и ждите остальных. Игра начинается сама, когда все выбрали фракцию.

Внизу лобби — три режима входа в игру:

| Режим | Что это |
|---|---|
| **Обычная игра** | Партия с нуля: галактика собирается тайлами, 2–4 игрока по сети. |
| **Готовая карта** | Та же партия 1 на 1, но карта уже собрана: игра начинается с планирования — удобно тестировать игру после постройки карты. Играется одним человеком, оба места за вами. |
| **Тест боя** | Наземный или космический бой: выбираете свои отряды (клик по отряду добавляет его, `1×…4×`) и карты в колоде, противника собирает игра. После боя — кнопка «Ещё бой»: то же поле и тот же состав. |

В тестовых режимах оба места принадлежат вам, интерфейс показывает,
чей сейчас ход («ТЕСТ · вы за обоих»).

Свой порт: `node tools/fs-server.mjs --port=9000`. Страница `/?demo=1` открывает
демонстрацию набора (маленький пример `js/Game.js`).

### Интерфейс и управление

У Forbidden Stars отдельный полноэкранный интерфейс поверх 3D-доски: лобби с выбором фракции,
состояние игроков и ресурсов, журнал партии, панель контекстных действий и подсказки. Сцена
игры не загружает демонстрационные мельницу и персонажа из ArcEngine.

Играется мышью, без панелей с десятками кнопок: всё, что нужно, — на самой доске.

- Перетаскивайте доску левой кнопкой мыши или одним пальцем; колесо мыши или щипок двумя пальцами меняют масштаб.
- Клик по своему отряду берёт его в группу (кольцо под фигурой), клик по второму — добавляет, ещё раз по тому же — убирает; кольца на соседних секторах показывают, куда можно идти, а стрелка — сам маршрут.
- Клик по сектору отправляет группу, и отряды едут по доске с анимацией; недопустимый сектор отвечает красной табличкой.
- Миры — плоские диски на доске: отряды и постройки стоят на них, а не рядом.
- Кнопка «⌖» возвращает камеру к доске, «?» открывает краткую справку, «⛶» включает полный экран.
- В лобби задайте имя, выберите свободную фракцию и отправьте друзьям ссылку или код комнаты.

### Как играть

- **Сборка карты** — в панели справа только сами системы; выберите тайл и кликните свободное
  соседнее место: на доске появится предпросмотр, который виден только вам. Поворот — только
  клавишами **Q/E**, другая сторона тайла — **F**; над системой висит табличка
  «Поставить», она же подтверждает размещение (рядом — «Отмена»). Карта для двух игроков получается 2×3 или 3×2;
  ориентация определяется по ходу раскладки. После каждого тайла
  выберите справа начальные отряды и постройки, затем кликайте по секторам текущего тайла —
  фигуры встают на диск мира. Уже поставленную фигуру можно убрать и переставить кликом.
  На третьем тайле размещаются все оставшиеся силы. Затем выберите жетон цели и кликните
  подсвеченный мир соперника — табличка над жетоном подтверждает постановку. После последнего
  тайла игроки по очереди выбирают систему на доске и её сторону справа для варп-шторма.
- **Планирование** — каждый кладёт четыре приказа в гексы систем (только в свою или
  соседнюю): наступление, развёртывание, стратегия, доминирование.
- **Операции** — приказы вскрываются по очереди: движение (и бой, или орбитальный удар),
  покупка отрядов и постройки, покупка улучшений, сбор ресурсов.
- **Обновление** — цели с дружественных миров, материя, ралл деморализованных, карта
  события и сдвиг варп-шторма.
- Победа: собрать столько жетонов целей, сколько игроков.

**Тестовые режимы** — для проверки без полной партии: «Готовая карта» (сразу
планирование и операции на собранной карте 1 на 1) и «Тест боя» (выбранные отряды
и карты в колоде на одном поле; бой можно перезапустить кнопкой «Ещё бой»).
Правила те же, что и в партии: тестовый режим только строит состояние.

Панель справа — только самое нужное на этот момент: сколько жетонов каждого вида у вас
осталось (`2× Кузница`, `0× Тайник` — нули видны сразу, считайте с одного взгляда),
выбранные отряды и одна кнопка «дальше». Панель слева — состояние игры и журнал;
подтверждения появляются табличками прямо над системой, жетоном цели или приказом.

### Правила применяет движок

Текст карты — это правило карты: движок сам читает его и применяет. Игрок не
истолковывает тексты — от него требуется только выбор из законных вариантов
(какого отряда деморализовать, какой кубик перебросить, куда поставить отряд).

- `js/fs/FSEffects.js` — интерпретатор текстов: предложение карты становится
  шагом игры (`получить жетон`, `потратить кубик`, `деморализовать отряд`,
  `разместить отряд`, `выбрать из двух`…), и исполнитель шагов: он задаёт игроку
  вопрос и ждёт ответа в `state.pending`.
- Приказ меняет правила игры, а не только её ход: вместимость миров, фабрики
  вместо городов, скидка, лимит улучшений, длина боя, запрет подкрепления —
  всё это движок держит в `state.order` и применяет сам.
- Схемы (планы) событий ждут своего момента: когда он настал, игрок решает,
  сбрасывать ли карту.
- `node tools/fs-coverage.mjs` — сколько текстов карт читает движок: сейчас
  **100 %** предложений разобрано (92 % становятся правилом, остальные 8 % —
  пояснения правил, которые движок показывает игроку).
- `node tools/fs-coverage.mjs --notes` — список этих пояснений (что именно
  уточняет карта); `--all` — предложения, которые движок пока не читает.

### Устройство

| Файл | Что внутри |
|---|---|
| `docs/forbidden-stars/*.md` | транскрипция правил и карт — источник данных |
| `tools/fs-import.mjs` | импорт markdown → `js/fs/FSData.js` (`node tools/fs-import.mjs`) |
| `js/fs/FSData.js` | данные: 12 фракций, 40 тайлов, карты боя, улучшения приказов, события |
| `js/fs/FSRules.js` | правила: фазы, приказы, бой, штормы, победа — чистая логика над состоянием |
| `js/fs/FSEffects.js` | тексты карт → шаги игры; движок применяет их сам |
| `js/fs/FSNet.js` | клиент: WebSocket до сервера |
| `js/fs/FSView.js` | доска в 3D: тайлы, отряды, постройки, цели, штормы |
| `js/fs/FSUI.js` | интерфейс: записи в `js/UILayout.js`, наполнение и кнопки |
| `js/fs/FSGame.js` | связка: состояние → доска и панели, клики → команды |
| `tools/fs-server.mjs` | сервер для локальной сети: статика + WebSocket (RFC 6455 вручную) |
| `tools/fs-coverage.mjs` | отчёт: сколько текстов карт читает движок |
| `tests/fs-*.test.mjs` | правила, команды, клиент, интерфейс и вся партия по сокету |

Сервер — единственный источник истины: клиенты шлют команды движка правил и получают
состояние (чужие руки не видны). Сокет и протокол — свои, без зависимостей.

Проверка: `node tools/check.mjs` (типы и тесты), тесты игры — `tests/fs-*.test.mjs`.

## Почему под LLM

- **Ноль зависимостей и сборки** — чистый JS, агенту нечего ломать в npm и бандлерах.
- **Агент знает правила** — `CLAUDE.md` и скиллы в `claude/skills/` описывают архитектуру до первой правки.
- **Агент проверяет себя** — типы и тесты одной командой, линтер сцены и инструменты отладки.
- **Вы — в редакторе, агент — в коде** — числа, объекты и UI лежат в файлах данных: их правите вы, логику пишет агент.
