# Ведьмак: Старый мир — статус

Запуск: `witcher.bat` (или `node witcher/server.mjs`), порт 8095. Проверка: `node witcher/tools/check.mjs`.

## Готово (базовая игра)

| Часть | Что есть |
|---|---|
| Данные | Все карты действий (70 стартовых + 90 общих), 31 монстр с трофеями, 20 карт атаки, 7 эликсиров, трофеи навыков и ведьмаков, поле 0–21 со смежностью — импорт из `Witcher/**/*.md` (`tools/import.mjs`, проверка свежести в воротах) |
| Сервер | Авторитетный, свой WebSocket, виды по местам (чужая рука, колоды, запас жизни монстра скрыты), отмена снимками (своё действие без открытой информации — сам игрок, остальное — хозяин), сохранение/загрузка, автосохранение при выходе в лобби и в конце, переподключение по токену, переход на свободное место с другого браузера, боты |
| Подготовка | 1–5 игроков по таблице стартовых ресурсов; вдвоём — выбор места монстра II уровня; вчетвером/впятером — доп. навык и стопка монстров; одиночная игра (3 монстра I–III, 5 карт, 3 золота) |
| Фаза I | Перемещение с тремя способами оплаты, действия всех локаций (школы, повышение навыка, выслеживание, эликсир, нищие кварталы, обмен, покер с горожанами) |
| Фаза II | Битва с монстром полностью: запасы жизни, жетоны следа, эликсиры, специализации всех 5 школ, способности и трофеи монстров, атаки удар/укус (выбирают соперники, соло — кубик), исход победа/изгнание/поражение; медитация |
| Фаза III | Добор, обязательная покупка из ряда со сдвигом, истощение, уровни ведьмака |
| Победа | 4 трофея, последний — из битвы; итог соло по таблице рангов |
| Клиент | Лобби (школа с 3D-миниатюрой, боты, настройки, сохранения, адреса в сети), 3D-стол: поле, миниатюры ведьмаков (цвет школы) и монстров (OBJ), подсветка доступных локаций, подсказка по наведению, анимация шага; панели участников, фаз, монстров, ряда, журнала, чата; рука и оплата перемещения; окно запросов; стол битвы с предпросмотром комбинации; покер с 3D-кубиками; экран победы; процедурный звук; горячие клавиши (F1) |
| Карты | Лица карт действий и атак 1:1 с печатными: рамки, медальоны, эмблемы, плашки, глифы вырезаны из сканов (`tools/frames.mjs` → `client/assets/cards/*.webp`), шрифты OFL (`client/fonts/LICENSE.md`); арт вырезан из фото карт в репозитории (`tools/art.mjs` → `client/art/*.webp`: 160 карт действий, 31 монстр, 7 эликсиров, 16 печатных карт снаряжения/спутников), меняется файлом |
| Миниатюры | Нормали исправлены, плоский цвет + тушь по выпуклым рёбрам как в waha (`client/toon.js`), без автоповорота в лобби и без покачивания на карте; модели 40k треугольников (`?tris=`), контур как в waha |
| Исследование | 287 карт из `Witcher/События/*.md`: база — все 36 карт города и 36 окрестностей + события «Ивенты 1»; генератор `tools/events-gen.mjs` → `shared/data/events-gen.mjs` (свежесть — в воротах), особые карты — `HAND` в генераторе, ручные правки — `OVERRIDES` в `events-data.mjs`. Каждая карта уникальна: разыгранная (и карта задания) уходит из игры навсегда (`state.eventsUsed`). Эффекты данными: золото, навыки ±, добор, сброс, щит, эликсиры (в т.ч. «доберите до N»), жетоны следа, удаление карты, карта из ряда, бесплатная покупка и скидка в фазе III, перемещение (соседняя локация или до 2–3 шагов), переход к фазе III, запрет исследования, цепочки событий, задания (в т.ч. «в своей или чужой школе»), броски кубика/по навыку/по уровню/«навык × 2 + кубик», комбинация из события (с добором или из руки), таблица по числу сброшенных эликсиров, условия, цена варианта (золото, эликсир, карта цвета, любая карта), «положите эту карту перед собой», покер (без своей ставки, с доп. перебросом горожан, против кубиков на карте). Открытые последствия: до выбора видны только жирные эффекты, описание — только выбранного варианта |
| Цири и доп. события | Галочка в лобби: в колоды замешиваются все 36 + 42 карты дополнения. Жетоны заданий для других игроков («кто придёт туда / закончит там ход» — событие зачитывается ему; жетон виден всем, номер события — только владельцу; «остаётся, но не для вас в этот ход»), тайные события (берутся в закрытую, у других видно только количество; срабатывают автоматически у первого другого игрока: перемещение в любую/конкретную локацию, конец фазы I в лесу, рост алхимии, победа над монстром, начало битвы в лесу, конец битвы с эликсиром, покер в локации), «магические кости» (второй переброс; при победе им — событие 133), спутники Гроббо (+1 карта после формирования запасов жизни) и Гертруда (без надбавки +1 ячейки ряда). Играбельная Цири — позже |
| Снаряжение и спутники | Все 14 карт «Ивенты 1»: Арбалет ×2, Доспех, Наручи, Кожаные сапоги, Кастет, Лекарство, Лошадь; Ярдель, Мартин, Оскар, Адья, Кая, Эдгар де Спота (после победы — событие 51). Ручные — кнопками в битве с причиной (только первый ход и т.п.), постоянные — сами (видны в подсчёте комбинации). Лошадь и «гильдия купцов» — кнопки перемещения в фазе I. Карты «перед собой»: меч Журавля (+1 урон синим), сумка для зелий (лимит 5), гильдия купцов, вырванная страница (тренировка −3), замена следующего исследования (4 золота / событие 30 / событие 55). В панели игрока — список, клик открывает карту |
| Режимы партии | Лобби: «Кастомная игра» (правила стола выбираются свободно) / «Игра на MMR» (все включены и заблокированы). Правила: возврат выпитых эликсиров после битвы за 1 золото; выбор бомбы и восстановление за 2 золота (заработает с дополнением «По следу монстра»); открытые последствия карт событий. Метка режима в верхней панели, правила — в подсказке. Песочницы берут режим из лобби |
| Управление | WASD — панорама камеры; горячие клавиши сняты с WASD (T локация, F битва, M медитация, исследование — только мышью, E завершить/пропустить, Q задание, R ряд, Z отмена); покупка в фазе III — только мышью, карты крупные, Alt+наведение — увеличение |
| Песочницы | В лобби: «битва» (рука «Мощный Аард» → «Блок» → красная, «Кастет», жетон следа), «покер», «исследование» (задание в соседней локации), «снаряжение» (8 карт снаряжения/спутников, 3 карты «перед собой», задание на событие 12 с комбинацией в соседней горной локации), «Цири и доп. события» (жетон задания бота рядом, тайная карта у бота, Гроббо и Гертруда, сверху колод — «магические кости» и баргесты), «середина партии» |
| Тесты | Аудит правил со ссылками на страницы, партии ботов на 1–5 игроков (только легальные команды, партии доходят до победы), то же с «Цири и доп. события»; 61 тест |

## Следующие этапы

1. Играбельная Цири (дополнение «Цири и доп. события»).
1. Бомбы (дополнение «По следу монстра») — вместе с правилом стола «Выбор бомбы и восстановление».
2. Битва ведьмак против ведьмака и покер с ведьмаком.
4. Боты умнее (оценка маршрута, покупка карт по колоде).
5. Дополнения из лобби: Легендарная охота, Скеллиге (острова 19–21 уже в данных), Чародеи, Цири и доп. события, По следу монстра, доп. монстр. «Дикая Охота» исключена.
6. Анимации карт (полёт в сброс/руку), 3D-кубики в сцене, музыка.

Арт карт вырезан из фото карт (`tools/art.mjs`). Свой арт: `witcher/client/art/<ID>.*` (см. README там же).
