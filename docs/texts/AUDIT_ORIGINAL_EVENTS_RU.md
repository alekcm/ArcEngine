# Повторная сверка карт событий оригинальной игры

Повторно просмотрен весь лист `Nemesis/Оригинальная игра/74B255A74711F8A5FD4F76CB115A6BA0F03A7FD4_Чужие - События.png`: 20 изображений, по два на увеличенной вырезке. Сверены названия, текст эффектов, цифры направлений и сами наборы символов Чужих на каждой карте с [переносом](CARDS_ORIGINAL_EVENTS_RU.md). Существенных расхождений при этом проходе не замечено.

Подписи типов движущихся Чужих в переносе соответствуют легенде на стр. 6; из-за противоречия со стр. 21 название «Трутень» может обозначать разные символы, поэтому связка символов и обе подписи сохранены в [сопоставлении легенд](RULES_ORIGINAL_INFECTION_WOUNDS_RU.md). Текст самих карт не исправлялся по догадкам. Это повторный просмотр тем же исполнителем, а не независимая гарантия отсутствия ошибок.
