# Карты событий

## Правила (из `01-rules-reference.md`, разделы *Event Cards*, *Refresh Phase*, *Warp Storms*)

- У каждой фракции своя колода событий. Карты событий дают эффекты и **управляют движением
  варп-штормов**: на каждой карте есть иконка движения шторма (две возможные стороны).
- В фазе обновления игрок берёт по одной карте за каждый жетон приказа, лежащий на его колоде
  событий (жетоны появляются там после приказа стратегии), выбирает **одну** карту, разыгрывает
  её и сбрасывает остальные.
- Если жетонов нет — игрок не тянет карт, но **всё равно** открывает верхнюю карту колоды, двигает
  шторм по её иконке и возвращает карту в колоду (эффект не разыгрывается).
- Два типа карт:
  - **ТАКТИКА** (tactic) — разыгрывается сразу и возвращается в колоду;
  - **ПЛАН** (scheme) — остаётся в игре лицом вверх, его эффект можно использовать дальше.
- Игрок может не разыгрывать эффект карты, но **обязан** выполнить движение шторма по её иконке.

## Что перепроверить

1. Каждый лист событий — дословно, по 6–8 карт на экран.
2. **Иконки движения варп-шторма** на каждой карте (две стороны: например «на север / на
   восток»). Без них не работает шаг штормов в фазе обновления — это ключевые данные для игры.
