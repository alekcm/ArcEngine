# Forbidden Stars — текстовый перенос всех материалов

Папка с текстовым описанием **всех** материалов настольной игры, которые лежат в
`Warhammer/`: правила, фракции, тайлы систем, карты, жетоны, модели. Смысл папки — чтобы
дальше работать с игрой по тексту, а не по картинкам: искать, сверять, спорить о правилах и
писать код, не переоткрывая по десять раз одни и те же фото.

## Что за игра

**Forbidden Stars** (Fantasy Flight Games, 2015; дизайн James Kniffen, Samuel W. Bailey,
Corey Konieczka) — варгейм по Warhammer 40 000 на 2–4 игроков. Поле собирается из квадратных
тайлов систем; у каждого игрока своя фракция с планшетом, отрядами и колодой карт. Раунд — три
фазы: планирование (выложить четыре жетона приказов), операции (выполнить их) и обновление
(цели, материя, события и варп-штормы). Побеждает тот, кто соберёт столько своих жетонов целей,
сколько игроков за столом, или у кого их больше после восьмого раунда.

## Как это читать

- **Правила** — в `01`. Там же таблица «буква → иконка», потому что в PDF иконки набраны
  шрифтом и в тексте превратились в буквы `B`, `D`, `C`, `A`, `E`, `V`. Формулировки оставлены
  по-английски: это первоисточник, по нему сверяют спорные случаи.
- **Числа отрядов** — в `02`. Русские названия — как на локализованных планшетах (гвардейцы,
  огрины, бойзы, гаунты…).
- **Тайлы** — в `03`, вместе с ASCII-схемой каждой системы.
- **Карты** — в `04`–`06`. Там, где текст прочитан по фото, он приведён дословно; где нет —
  честно написано «не перенесено» и указано, на каком листе это лежит.

## Про точность

Материалы — это фотографии компонентов, местами под углом, местами в мелком разрешении, а часть
листов (17/20/21/22-е тайлы новых фракций) — один огромный лист на все карты сразу. Правила
перенесены полностью и точно (PDF с текстовым слоем). Данные планшетов перенесены полностью:
они читались по увеличенным вырезкам, и все 12 планшетов сверены между собой на
непротиворечивость (город 3 / фабрика 2 / бастион 2-3-2 у всех; по 6 отрядов, кроме Тёмных
эльдаров с 5). Карты и баннеры миров — там, где стоит пометка `?`, значение прочитано
неуверенно.

Раздел «Что перепроверить» есть в конце каждого файла — это список того, что осталось дочитать,
в порядке полезности для игры.
