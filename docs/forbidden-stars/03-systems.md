# Тайлы систем

## Что такое тайл

Тайл — квадрат, разделённый золотыми линиями на **четыре области** (area). Каждая область —
либо **мир** (world: планета + баннер со значениями), либо **пустота** (void: звёздное поле без
баннера). В центре — **гекс приказов** (order token box), клетка, куда кладут жетоны приказов.

Правила (из `01-rules-reference.md`, разделы *Adjacency*, *Areas*, *Worlds*, *Voids*,
*Unit Capacity*, *Assets*, *Systems*):

- Две системы соседние, если у них общая золотая граница (угол — не граница).
- Две области соседние, если у них общая золотая граница. Области, соединённые только гексом
  приказов или углом, не соседние.
- **Мир**: у каждого баннера — стоимость в материи (зелёная шестерёнка с числом), **вместимость**
  (число черепов) и, у части миров, **иконка ресурса** (сургучная печать). Вместимость = число
  черепов на баннере.
- **Пустота**: вместимость всегда 3, материи не даёт, ресурсов не даёт. Корабли стоят в пустотах,
  наземные отряды могут проходить через пустоты, но не стоять в них.
- Ресурсы (assets) приносят только миры, и только при приказе **доминирования**: за каждый
  дружественный мир в активной системе игрок получает ресурс, нарисованный на баннере.

### Обозначения в таблицах ниже

| Обозначение | Значение |
|---|---|
| `ПЛ` / `ПП` / `НЛ` / `НП` | положение области на тайле: право-верх / лево-верх / лево-низ / право-низ |
| `мир` / `пустота` | тип области |
| `M:` | материя (шестерёнка на баннере), `—` — не указана |
| `Вм:` | вместимость (черепа на баннере) |
| `Р:` | иконка ресурса на баннере: `кузница`, `тайник`, `подкрепление`, `процветание`, `—` нет |

> **Статус точности.** Имена миров, тип области и наличие баннера прочитаны с фотографий
> уверенно. Числа материи/вместимости и иконки ресурсов прочитаны с масштабированных снимков;
> мелкие иконки на баннерах (особенно где печать одна, а не две) могут быть перепутаны —
> такие места помечены значком `?`. Раздел «Что перепроверить» в конце файла.

## Базовые 16 тайлов (`Warhammer/Системы/`)

Файлы названы `<номер><буква>.jpg`: номер 1–8 — «семейство» тайлов, буква A/B. Все 16 — квадраты
2126×2126. **Важно:** файлы `1б` и `2б` отсканированы/сохранены повёрнутыми на 180° (надписи
вверх ногами, номер тайла в левом верхнем углу); при чтении и при сборке игры их надо
переворачивать.

Внутренняя разметка у всех тайлов одна и та же: гекс приказов в центре, четыре области по углам,
золотые линии идут «змейкой» от угла к углу через центр. Угловые области каждой пары соседствуют
по вертикальной или горизонтальной линии (см. ASCII-схему каждого тайла).

## Что перепроверить (по возрастанию трудоёмкости)

1. **Числа на баннерах** (материя + черепа) у всех 64 миров — нужен кроп каждого баннера в
   полном разрешении. Формат уже готов: баннер — вертикальная лента, её надо повернуть на 90°.
2. **Иконки ресурсов.** По правилам их четыре: кузница (forge), тайник (cache),
   подкрепление (reinforcement), процветание (prosperity, белый орёл — «получи ресурс на выбор»).
   На баннерах встречаются одна или две печати; часть печатей — с белым флагом/звездой, часть —
   золотая шестерёнка, часть — зелёная. Нужна сверка с артом токенов (`AssetForge.jpg`,
   `AssetCache.jpg`, `AssetReinforcement.jpg`, `ShieldGunToken.jpg`).
3. **Внутренняя соседность областей** (какие из четырёх областей тайла разделены золотой линией).
   На всех базовых тайлах рисунок одинаковый («змейка»), но для игры нужна проверка на 2–3
   тайлах разных семейств.
4. **Тайлы 17/20/21/22** — перечитать в полном разрешении (по половине листа на тайл).
