# Что перенесено в текст и что нужно сверить

Это «оглавление транскрипции + список сомнительных мест». Читать так: сначала таблица файлов
(что где лежит), потом статус каждого файла, потом список открытых вопросов — по приоритету,
с точным адресом каждого (файл → раздел → карта/мир).

Ничего не переписано «по памяти»: всё читалось с фотографий из `Warhammer/` и вписывалось в файлы
только после того, как я видел кроп. Но фотографии — это фото карт на столе: блики, наклон, мелкий
шрифт. Поэтому часть символов читалась неуверенно, и такие места помечены `?`.

## 1. Обозначения, которые я использую

| Запись | Значение |
|---|---|
| **КЛ** | командный уровень карты (золотой круг слева сверху) |
| **Стоимость** | зелёная шестерёнка с числом (материя) |
| `наст` / `обор` / `мор` | иконки на кубике: болтер / щит с черепом / крылатая аквила |
| `V` | контур кубика: «возьмите кубик из запаса и бросьте» |
| `жетон-наст`, `жетон-обор` | жетоны, а не грани кубика (встречается в старых разделах) |
| `?` | прочитано неуверенно, нужно сверить |
| **ПЛАН** / **ТАКТИКА** | тип карты события (плашка на карте) |
| `ПЛ` `ПП` `НЛ` `НП` | положение области на тайле: право-верх / лево-верх / лево-низ / право-низ |
| **M** / **Вм** / **Р** | материя (шестерёнка) / вместимость (черепа) / иконка ресурса |

## 6. Как удобнее присылать правки

Формат, который я пойму без уточнений: **файл → раздел → название карты/мира → что верно**.
Например: «`04` → Адептус Механикус → Шустрое судно → стоимость 3, а не 4» или
«`06` → Орки → Моар бойз! → шторм двигается на север и на юго-запад».

Если проще — можно просто сказать «в разделе X всё, кроме двух карт, верно, у N-й иконка другая»:
я перечитаю раздел точечно.
