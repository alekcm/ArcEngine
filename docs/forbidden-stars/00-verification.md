# Что перенесено в текст и что нужно сверить

Это «оглавление транскрипции + список сомнительных мест». Читать так: сначала таблица файлов
(что где лежит), потом статус каждого файла, потом список открытых вопросов — по приоритету,
с точным адресом каждого (файл → раздел → карта/мир).

Ничего не переписано «по памяти»: всё читалось с фотографий из `Warhammer/` и вписывалось в файлы
только после того, как я видел кроп. Но фотографии — это фото карт на столе: блики, наклон, мелкий
шрифт. Поэтому часть символов читалась неуверенно, и такие места помечены `?`.

## 1. Обозначения, которые я использую

| Запись | Значение |
|---|---|
| **КЛ** | командный уровень карты (золотой круг слева сверху) |
| **Стоимость** | зелёная шестерёнка с числом (материя) |
| `att.` / `def.` / `morale` | иконка **без рамки** — вклад самой карты: наступление / оборона / мораль (болтер / щит с черепом / орёл) |
| `att. token`, `def. token` | **жетон** боя: наступление / оборона (иконка в круге) |
| `att. cube`, `def. cube`, `morale cube` | **кубик** с этой гранью (иконка в квадрате или на видимой грани кубика) |
| `any cube` | **пустой кубик**: взять кубик из запаса и бросить, грань любая |
| `?` | прочитано неуверенно, нужно сверить |
| **ПЛАН** / **ТАКТИКА** | тип карты события (плашка на карте) |
| `ПЛ` `ПП` `НЛ` `НП` | угол области на тайле: **верх-лево / верх-право / низ-лево / низ-право** |
| **M** / **Вм** / **Р** | материя (шестерёнка) / вместимость (черепа) / иконка ресурса |

  без рамки — `att.` / `def.` / `morale`; в круге — `att. token` / `def. token`;
  в квадрате или на грани — `att. cube` / `def. cube` / `morale cube`; пустой кубик — `any cube`.

- **Иконки кубов и жетонов путались (нашёл владелец набора).** В `04` иконки читались как один

  карте стоял куб с конкретной гранью. Пример ошибки: «Ратлинги стрелков» — на карте сверху
  `A` (противник теряет 2 жетона наступления), снизу `V` (потратит любой куб); в файле было
  наоборот. Введены коды из PDF правил: `A`/`E` — жетоны, `B`/`D`/`C` — кубы с гранью,
  `V` — пустой куб; иконка без рамки — `наст`/`обор`/`мор`. Легенда переписана, Имперская
  гвардия перечитана целиком по новой схеме (5 базовых + 9 улучшений), остальные фракции —
  по очереди следующими.
- **Как читаются иконки.** Иконка на скане — 30×30 px. Находится как компактный тёмный блоб в
  текстовой полосе (размер 25–50 px, площадь 300–1500 px), вырезается 60×60 и увеличивается
  в 12–24 раза; на этом увеличении видно обёртку: круг = жетон, квадрат/грань кубика = куб
  с гранью, объёмный кубик без иконки = `V`, грань без рамки — только в левой колонке карты.
  Один и тот же глиф (болтер / щит с черепом / орёл) узнаётся по форме, поэтому тип обёртки и
  тип иконки проверяются отдельно.
- **Места под жетоны целей.** В первой версии я записал «жетон можно ставить в любой мир», из-за
  чего у трёхмировых тайлов выходило по три места. Неверно: место под жетон — это кремовая
  «бирка» на поверхности планеты, и таких мест **ровно два на тайл** (всего 80). Раздел
  переписан: угол + имя для каждого из двух мест и отдельно мир без места (14 штук).
- **Раскладка мест под жетоны целей.** Владелец набора проверил её по всем 40 тайлам и задал
  правило: у 2-мировых тайлов места на обоих мирах независимо от их положения, у 3-мировых —
  строго по диагонали (`ПП`+`НЛ` или `ПЛ`+`НП`), исключение одно — `18B`, где места на двух
  нижних мирах (`НЛ` `Sulus Omega`, `НП` `Runux 2`; верхний `ПЛ` `Sulymaan` без места).
  Правило и сводка по диагоналям добавлены в `03`, таблица сверена — правок не потребовалось.
- **Углы `ПЛ/ПП/НЛ/НП`.** В легенде они были расшифрованы наоборот («право-верх» и т. д.);
  исправлено на верх-лево / верх-право / низ-лево / низ-право. По этой же легенде поправлены
  `2B` (`Ferricus`), `3B` (`Gorm`), `4B` (`Barracha`) и `10B` (три мира).
- **`1A`** — мир вверху-слева называется `Alco`, а не `Hiveo` (прочитано кропом в 2:1).

- **Иконки перечитаны по PDF, а не по догадке.** В самом PDF правил есть раздел *Icon Reference*:
  `B, D, C` — иконки **на боевых кубиках**, `A, E` — иконки **на жетонах боя**, а знак **без
  обёртки** — «combat icon on any component». Отсюда жёсткая схема чтения: круг с силуэтом =
  жетон, квадрат с тёмным глифом = кубик с конкретной гранью, объёмный пустой кубик = `any cube`,
  знак без рамки = значение (`att.` / `def.` / `morale`). **Жетонов морали не существует.**
  Легенда `04` переписана под это, добавлено приложение «Метод читки иконок».
- **Левая колонка карты — не иконки.** У Некронов в левой белой колонке повторяется декор
  (эмблема в гексе, «ключ с шариками»), и авто-детектор находил там «иконки», которых нет.
  Читать нужно только рамки **внутри текста** способности. Прежние ошибки в разделе Некронов
  именно оттуда.
- **Силуэт внутри жетона тоже надо читать.** В круге бывает не только болтер: у Некронов в
  жетонах нарисован танк, у Имперской гвардии («Огневая поддержка») — щит с черепом, то есть
  жетон бывает оборонительным. Поэтому `att. token` нельзя ставить только по позиции жетона
  в атакующей части карты.
- **Имперская гвардия — правки владельца набора внесены.** «Подавляющий огонь виверн» и
  «Ратлинг стрелок» (названия), «Огневая поддержка» — противник теряет 2 `def. token` (не кубика),
  «Часовой разведчик» — избежать эффекта можно за `morale cube` (не за `att. cube`),
  «Огринские ударные войска» — в колонке только два `att.`, перебрасываются `def. cube` и/или
  `morale cube`, способность отряда даёт `def. token` за каждого недеморализованного Гвардейца
  или Крейсера (максимум 3).
- **Некроны перечитаны целиком** (14 карт с `БК1.jpg` и `БК3.jpg`): почти в каждой карте тип
  носителя был другой. `БК3.jpg` опознан как лист Некронов (5 улучшений + 4 базовые), а не
  «фракция не опознана».

- **Некроны и Тираниды перечитаны по кропам (а не по общему снимку листа).** Обе колоды разбиты
  правильно: в колоду входят 10 карт с эмблемой фракции в углу, а карта с жёлтым щитом (КЛ) и
  зелёной шестерёнкой (стоимость) — это боевое улучшение (PDF, *Combat Cards and Combat Upgrade
  Cards*). У Некронов 5 базовых карт (по 2 копии) и 9 улучшений, у Тиранидов на фото 3 базовые и
  6 улучшений (двух базовых карт на снимке нет).
- **Метод чтения иконок стал измеримым.** Носитель определяется заполненностью углов залитой рамки
  (0 — круг-жетон, 1 — квадрат-грань кубика, 0,5 — изометрия, то есть `any cube`); глиф удобнее
  читать в левой колонке карты, где те же знаки крупнее: орёл — ширина/высота ≈ 2,3, щит ≈ 0,8,
  болтер ≈ 0,95 и при этом несимметричный (симметрия ≈ 0,4). Орёл в 30 px выглядит как наклонный
  «веер», из-за чего раньше не опознавался.
- **Что дали эти две фракции по существу.** Некроны: «Лич гвардия» — 2 `def. token` (круг), а
  «Разрушители» тратят `def. cube`/`morale cube` и выдают 2 `att. token`; у «Осколка несущего
  ночь» в колонке три значка, а не два. Тираниды: «Крушащие клешни» — 3 `att. token`, «Величие
  роя» тратит `morale cube`, «Крылатый ужас» — КЛ 0 и `morale cube` вместо `att. cube`.

## 6. Как удобнее присылать правки

Формат, который я пойму без уточнений: **файл → раздел → название карты/мира → что верно**.
Например: «`04` → Адептус Механикус → Шустрое судно → стоимость 3, а не 4» или
«`06` → Орки → Моар бойз! → шторм двигается на север и на юго-запад».

Если проще — можно просто сказать «в разделе X всё, кроме двух карт, верно, у N-й иконка другая»:
я перечитаю раздел точечно.
